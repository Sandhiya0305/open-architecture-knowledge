# Technology Ecosystem Guides

These guides map architecture concepts to implementation choices. They must not imply that a framework enforces an architecture automatically.

Planned ecosystem guides:
- [Node.js](nodejs/README.md)
- [Python](python/README.md)
- [Java](java/README.md)
- [PHP](php/README.md)

Each guide should cover relevant language/runtime characteristics, common frameworks, module and dependency conventions, testing approaches, deployment considerations, and links to architecture references. Claims about performance must point to benchmark records with reproducible methodology.
