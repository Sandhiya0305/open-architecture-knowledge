# About OAI

Open Architecture Knowledge is a practical, source-backed reference for understanding software architecture and making engineering decisions.

The goal is simple: explain concepts clearly, show useful design trade-offs, and make it easy to trace information back to its sources.

## What guides the content

- **Clarity:** concise explanations without unnecessary complexity.
- **Accuracy:** no invented claims, references or benchmark results.
- **Context:** architecture choices depend on requirements and constraints.
- **Practicality:** examples and diagrams are included when they improve understanding.
- **Transparency:** sources and evidence limitations are visible.

## Contribute

Corrections, clearer explanations and useful new topics are welcome. See the [contribution guide](contributing.md).

The companion [OAI research project](https://github.com/Sandhiya0305/open-architecture-intelligence) supports discovery and review. This site contains the curated knowledge intended for developers.
