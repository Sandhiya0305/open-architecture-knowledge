# Reusable AI Skills

This directory will contain task-specific instructions for AI assistants that consume this knowledge base.

Planned skills:
- Architecture selector: compare candidate styles against explicit requirements and constraints.
- Architecture reviewer: inspect a proposed design for coupling, boundaries, data ownership, resilience, and operational risks.
- Project planner: propose an incremental architecture and implementation plan.

Skills must cite the relevant knowledge pages, distinguish evidence from assumptions, state uncertainty, and never invent benchmark results.
